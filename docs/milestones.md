# SimpleBlog Milestones

## 执行约定

- Milestone 按 M0 到 M7 顺序执行。
- 每个 Milestone 必须独立通过验收后才能进入下一个。
- 每完成一个 Milestone 创建一个签名 Git commit，并通知项目所有者验收。
- 所有应用层业务结果返回 HTTP 200，真实状态由响应体 `code` 表示。

## M0：工程与数据库基线（已完成，等待验收）

目标：建立后续业务功能依赖的稳定运行基础。

范围：

- 创建 PostgreSQL 初始 schema：users、categories、posts、comments 及索引。
- 增加配置校验和数据库启动 Ping。
- 为 HTTP Server 增加超时与优雅关闭。
- 统一 handler、middleware、404、405 和 panic 的响应协议。

验收：

- 空数据库能够执行初始 schema。
- 配置或数据库不可用时服务拒绝启动。
- 服务能够响应关闭信号并在超时内退出。
- 所有应用兜底错误均为 HTTP 200 + body code。
- `gofmt -d`、`go vet ./...`、`go test ./...` 通过。

## M1：用户、登录与权限体系（待开始）

目标：完成 admin/contributor 身份与授权基础。

范围：User 语义重构、用户 CRUD、软删除、bcrypt、JWT、当前用户加载、角色守卫、最后一个 admin 保护、首个 admin CLI。

验收：角色矩阵测试通过；删除或改角色后旧 JWT 不能继续授权；最后一个 admin 不能删除或降级。

## M2：分类与文章后台（待开始）

目标：完成后台内容生产闭环。

范围：分类 CRUD、文章 CRUD、Markdown + LaTeX 原文、TEXT[] 标签、draft/published、发布与撤回。

验收：contributor 只能操作自己的文章；admin 可操作全部；分类、slug、状态冲突返回正确业务 code。

## M3：公开内容 API（待开始）

目标：向前端提供稳定的公开读取接口。

范围：已发布文章列表与详情、分类与标签列表、筛选、稳定分页。

验收：公开接口不泄露草稿；slug、分类、标签和分页边界测试通过。

## M4：多级评论（待开始）

目标：支持匿名评论、任意层级回复和后台审核。

范围：顶级评论、回复、Turnstile、同文章父子校验、评论树、隐藏/恢复、deleted 墓碑、评论权限。

约束：后端不限制回复深度；前端采用类似 B 站的不随层级增加缩进的展示。

验收：删除父评论后显示“该评论已被删除”且子回复保留；公开数据和日志不泄露邮箱。

## M5：S3 图片直传（待开始）

目标：让前端安全地直接上传正文图片到 S3 兼容服务。

范围：预签名接口、服务端 object key、公开/CDN URL、Content-Type 与大小限制。

约束：只允许 JPEG、PNG、WebP、GIF，单文件最大 10 MiB。

验收：文件内容不经过 Go 服务；真实 S3 兼容环境上传和公开读取成功。

## M6：质量与安全加固（待开始）

目标：补齐上线前的工程质量和滥用防护。

范围：请求限制、分页上限、结构化日志、敏感信息过滤、数据库错误分类、service/handler/repository 测试。

验收：格式、静态检查、全量测试通过；敏感数据不进入响应和日志。

## M7：发布验收与文档冻结（待开始）

目标：形成可部署、可验证、文档一致的首个版本。

范围：CI PostgreSQL、环境变量示例、初始化与部署流程、完整验收清单、文档复核。

验收：新环境可以按文档完成部署；所有 milestone 验收项在 CI 或可重复的本地流程中通过。
